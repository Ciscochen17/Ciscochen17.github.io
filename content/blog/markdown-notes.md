Markdown 用一些简单的符号表示文章结构。写的时候保留纯文本的轻巧，阅读时又能得到清晰的排版。

这份笔记整理了小站编辑器支持的常用写法。你可以把示例复制到日记里，切换预览查看效果。

## 标题与段落

在行首加上 `#` 表示标题。文章本身已经有标题时，正文建议从二级标题开始。

```markdown
## 今天的小事

这是第一段。段落之间空一行。

### 一个小发现

这是一段更细的记录。
```

## 强调与链接

用两个星号包住文字可以 **加粗**，一个星号表示 *斜体*。

```markdown
今天记住了一件 **重要的小事**。

参考资料：[GitHub 文档](https://docs.github.com/)
```

链接最好使用能说明内容的文字，方便回看时快速判断去向。

## 列表与待办

无序列表适合整理零散想法，有序列表适合描述步骤。

```markdown
- 散步时想到的点子
- 值得继续研究的问题

1. 打开笔记
2. 写下第一句话
3. 留一个明天可以继续的话题

- [x] 写下一段记录
- [ ] 整理本周的笔记
```

## 引用一段话

在行首使用 `>`：

```markdown
> 不用写得很长，先把今天留住。
```

> 不用写得很长，先把今天留住。

## 代码与技术笔记

短代码可以用行内反引号包住，例如 `git status`。多行代码使用三个反引号，并可注明语言。

```javascript
const note = {
  title: '今天的小发现',
  tags: ['日常', '学习']
};
console.log(note.title);
```

代码块右上角支持复制，方便保存命令和小片段。

| 整理收藏 | 删除失效链接 |

## 让记录保持可迁移

日记可以导出为 `.md` 文件，用其他文本编辑器继续打开。日记页面里的草稿保存在当前浏览器；导出可以保留自己的副本，加入仓库的公开日记数据后才会对所有访客可见。

Markdown 的好处之一，就是文字不会被固定在某一个编辑器里。
